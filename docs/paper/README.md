# راهنمای جامع معاملات کاغذی زنده (Paper Trading Guide)

> **امنیت و معماری**: این ماژول کاملاً **فقط‌خواندنی (Read-Only)** است. هیچ کلید API خصوصی، امضای تراکنش یا قابلیت ارسال سفارش به صرافی در کل کدبیس وجود ندارد. دریافت داده‌ها منحصراً از Endpointهای عمومی رایگان صرافی بایننس صورت می‌گیرد.

## ۱. ساختار دفاتر معاملاتی (Trading Books)

| مشخصه | دفتر A (Book A: F3 Long-Only) | دفتر B (Book B: C1L Conservative) |
| :--- | :--- | :--- |
| **استراتژی پایه** | `fisherMode: 'confirm'` | `fisherMode: 'extra-trigger'` |
| **جهت معامله** | فقط‌خرید (`tradeMode: 'long-only'`) | فقط‌خرید (`tradeMode: 'long-only'`) |
| **سایز هر پوزیشن** | ۳٪ کل سرمایه حساب | ۲٪ کل سرمایه حساب (محافظه‌کارانه) |
| **سقف پوزیشن همزمان** | حداکثر ۱۰ پوزیشن | حداکثر ۵ پوزیشن (مهار همزمانی) |
| **سقف مواجهه کل** | حداکثر ۳۰٪ سرمایه | حداکثر ۲۰٪ سرمایه |
| **تریلینگ‌استاپ** | پله‌ای ۵٪ / ۳٪ / ۱.۵٪ | پله‌ای ۵٪ / ۳٪ / ۱.۵٪ |

## ۲. دستورهای اجرا (Execution Commands)

### الف) اجرای تک‌مرحله‌ای (One-Shot Execution)
برای به‌روزرسانی کندل‌ها، پردازش سیگنال‌ها، به‌روزرسانی پوزیشن‌ها و تولید گزارش در یک نوبت:
```bash
npm run paper:once
```

### ب) اجرای پیوسته به صورت دیمون (Watch Mode)
برای اجرای خودکار در پس‌زمینه و بررسی کندل‌های جدید در فواصل زمانی منظم (پیش‌فرض هر ۵ دقیقه):
```bash
npm run paper:run
```
برای تغییر بازه زمانی بررسی (مثلاً هر ۶۰ ثانیه):
```bash
npx tsx src/paper/cli.ts --watch --interval 60
```

## ۴. مکانیزم توقف اضطراری (HALT Circuit Breaker)

سیستم مجهز به سوئیچ ایمنی خودکار برای مهار ریسک نزولی است:

1. **تریگر خودکار**:  
   چنانچه بیشینه افت سرمایه (Drawdown) هر دفتری در حین اجرا به **$\ge 10.0\%$** برسد، سیستم فوراً فایل پرچم توقف را ایجاد می‌کند:
   - `data/paper/HALT_A` برای دفتر A
   - `data/paper/HALT_B` برای دفتر B
2. **رفتار هنگام توقف (HALT)**:
   - ثبت هرگونه **ورود جدید ممنوع** شده و سیگنال‌های جدید رد می‌شوند.
   - پوزیشن‌های بازی که از قبل وجود داشته‌اند همچنان طبق منطق تریلینگ‌استاپ پایش شده و با رسیدن به حد ضرر به طور ایمن بسته می‌شوند.
3. **ری‌ست دستی (Manual Reset)**:
   برای رفع وضعیت توقف پس از بررسی علت، کافی است فایل پرچم حذف شود:
   ```powershell
   Remove-Item data/paper/HALT_A -Force
   # یا در لینوکس:
   # rm data/paper/HALT_A
   ```

## ۵. پروتکل ارزیابی و تصمیم‌گیری

مطابق با تعهدات ثبت‌شده در `PREREGISTERED_PT.md`:
- ارزیابی عملکرد و مقایسه دو دفتر صرفاً پس از سپری شدن **حداقل ۹۰ روز تقویمی** و بسته شدن **حداقل ۳۰ معامله** در هر دفتر انجام می‌پذیرد.
- پیش از احراز این دو شرط، هیچ‌گونه تصمیم‌گیری درباره اتصال به حساب واقعی یا ارتقای پارامترها اتخاذ نخواهد شد.
- معیار پذیرش صحت اجرا: اختلاف بازدهی اجرای کاغذی با بازپخش بکتست همان کندل‌ها باید $\le 20\%$ نسبی یا $\le 2\%$ مطلق باشد.
