# TradeBot

Crypto Trading Bot with Backtesting Engine.

## Setup

```bash
npm install
```

## Usage

```bash
# Run the bot
npm start

# Run tests
npm test

# Run tests in watch mode
npm run test:watch

# Build the project
npm run build

# Lint the code
npm run lint
```

## Project Structure

```
src/          # Source code
tests/        # Test files
dist/         # Compiled output (generated)
data/         # Data files
```
